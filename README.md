
# CSV Summary Counter

## Project Overview
A beginner-friendly Python project that reads a CSV file and generates summary counts.

## Features
- Reads CSV files using Python's built-in csv module.
- Counts total records.
- Calculates the frequency of values in a selected column.
- Handles blank department values.
- Displays a simple summary in the terminal.

## Technologies Used
- Python
- CSV module
- Collections Counter

## Project Structure
csv_summary_project/
- employees.csv
- csv_summary.py
- README.md

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

python csv_summary.py
